## 2. 终端连接工具

宿主 Windows 上已安装并可使用多种终端工具：

- **Xshell / Xftp**（NetSarang）：图形化 SSH 客户端；
- **Git Bash**（Git 2.55.0）：命令行环境；
- **Windows OpenSSH 客户端**：`ssh` 命令。

## 3. OpenSSH 服务与远程连接

虚拟机内 SSH 服务正常运行：


宿主机测试 22 端口连通性成功，并通过 SSH 成功登录虚拟机执行命令（本清单中的环境信息即通过 SSH 远程采集）。
